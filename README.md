# 발표자 뽑기 (Class Picker)

학생 명단에서 발표자를 무작위로 뽑아 주는 한 페이지짜리 웹 앱입니다.
빌드 도구나 서버 없이 `index.html` 파일 하나로 동작합니다.

## 사용 방법

- **🎲 뽑기** — 아직 뽑히지 않은 학생 중 한 명을 무작위로 뽑습니다.
- **↺ 처음으로** — 뽑기 기록을 지우고 전체 명단에서 다시 시작합니다.
- **✎ 명단 편집** — 한 줄에 한 명씩(또는 쉼표로 구분해) 명단을 입력합니다.

## 특징

- 이미 뽑힌 학생은 다시 뽑히지 않습니다 (동명이인도 각각 따로 관리).
- 명단과 뽑기 기록은 브라우저 `localStorage`에 저장되어 새로고침해도 유지됩니다.
- 저장이 막힌 환경(사생활 보호 모드 등)에서도 앱은 그대로 동작하며, 안내만 한 번 표시됩니다.
- 화면 크기에 맞춰 글자 크기가 조절되어 교실 화면에 띄우기 좋습니다.

## 로컬에서 실행

`index.html` 을 브라우저로 열기만 하면 됩니다.
